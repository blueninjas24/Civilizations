# Completed village-owned homes

Current internal backend: `CivBuildingCompletion`, schema116. Ordinary automatic
construction is still off; full completed-house native acceptance remains pending.

The frozen home plan produces stable building/unit UUIDs and one explicit private
unit with the original transformed bed pairs. No inferred apartments, rent, private
family title or new people. Village-funded ownership follows the approved rule.

Completion requires a present permanent world, fresh complete native frame, every
native block acknowledged, actual paid supplier goods and matching earned public
stage effort. Current site/protection must still permit registration. One
transaction saves layout, units, use, Civ origin, family completion and temporary
site release. The permanent building footprint stays protected. A late failure
preserves the whole previous project; history is never erased.

`civ_built_buildings` identifies the village contributor explicitly. Existing player
records remain PLAYER. The legacy SQL `donor_id` slot holds the typed village
contributor for Civ origin; public `Entry.donor()` is null there. Player donation,
reclamation and renovation-consent routes reject Civ origin, even for an admin or
matching UUID. Admin inspection stays available. No player declaration is invented.

The common use ledger's legacy DONATE action means granting village use for these
explicit Civ records, rather than a player donation. Existing player title/consent
history is unchanged. Renovation and decay of player additions remain separate work.

Completion grants no housing capacity. The existing loaded-only dwelling review
must observe actual paired beds, support, headroom, cover and access, then assign
a whole eligible household. Unknown evidence holds; confirmed damage reduces
capacity. A completion retry returns history and never restores damaged housing.

Finished bindings leave the active project cap and unique household slot without
pretending to be cancelled. Confirmed later housing loss can request a replacement.
Empty qualified homes remain in the shared vacancy flow; the building stays owned
by the village when its occupants change or die.

Authored bed heads bind their original village before native placement. Positive
old journal provenance backfills transactionally during migration; foreign village
identity refuses. These bed coordinates never become early/duplicate legacy
capacity. The existing inspected-unit bed claims remain the actual occupancy
authority. No physical bed is fabricated by registration or migration.

Tests use only temporary SQLite databases: actual supplier payments/delivery and
earned four-stage work, complete native-journal evidence, no early capacity,
functional domain inspection/assignment, restart, late rollback, typed owner
authority,115 upgrade failure/retry, and later damage/replacement/replay. This is
not yet a claim of an ordinary autonomous builder or native finished-home proof.
