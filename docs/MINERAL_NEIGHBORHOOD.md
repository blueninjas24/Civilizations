# Known loaded neighbor snapshots

Verified October 13, 2026: six new adapter tests and the full Windows Wrapper
`.\mvnw.cmd clean verify` passed 1,339 cases (1,337 unit and two packaged
integration), with no failures, errors or skips. The guarded disposable Paper
probe passed at 08:04:41 ET: five real snapshots matched 32 independently checked
stone/sand positions, and the ordinary ore observer saved current owner-validated
evidence. No blocks/entities were edited; only the helper used temporary tickets.
The save audit found 116/120 tables unchanged, four ordinary clock/evidence
changes, healthy integrity/foreign keys and preserved assets/history. Original
properties were restored and the helper archived. No playable server was changed.

The default ore observer now captures the centre chunk and up to four already-loaded cardinal neighbors on Paper's main thread. The immutable neighborhood adapter resolves only the one-cell six-face boundary needed by the existing scanner. Missing chunks, diagonal/out-of-range coordinates and outside-world height remain unknown; no chunk is loaded to supply missing evidence. Centre/global coordinates remain stable, and resources in neighbor chunks are not admitted as centre survey members.

This fixes a practical quarry-survey dependency: buried stone at chunk borders could not be ruled out as exposed when the neighboring face was unknown, so single-chunk quarry scans frequently remained incomplete. The same adapter supports the separate stone/deepslate and sand/red-sand classifier while preserving default coal/iron mode. Cross-world/misaligned snapshots and overflow coordinates are rejected before block reads.

Snapshot capture remains bounded at at most five snapshots for one target; scan budgets are unchanged. This increases capture cost compared with one snapshot. A broad multi-town profile gate remains open; no low-latency or scale guarantee is claimed. The runtime never forces chunks. Native fixture-only chunk tickets are explicitly setup and released after testing.

No migration or automatic quarry founding is added. Quarry-family durable survey storage, current demand/owner/funding acceptance and a live quarry observer remain separate integration work. The existing coal/iron observer now uses the neighborhood source. Source evidence cannot establish reserves, rights over player buildings, or permission to dig blocks.
